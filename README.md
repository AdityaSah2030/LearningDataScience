# Data Science Foundations

A clean and minimal repository designed for learning and rapid revision of core data science concepts and libraries.

## 🎯 Purpose
This repository is structured to help you revise data science fundamentals quickly. It serves as a personal knowledge base covering essential Python libraries and machine learning workflows used in data analysis, visualization, and predictive modeling.

## 📂 Structure
- `01_numpy/` - Core concepts of numerical computing, including array manipulation, indexing, slicing, and broadcasting.
- `02_pandas/` - Essential data manipulation and analysis, covering dataframes, filtering, aggregation, and data cleaning.
- `03_matplotlib/` - Fundamentals of data visualization, covering line plots, scatter plots, subplots, and figure customization.
- `04_seaborn/` - Statistical data visualization, covering distribution plots, categorical plots, and correlation heatmaps.
- `05_scikit_learn/` - Machine learning fundamentals, covering data preprocessing, linear regression, classification, and model evaluation workflows.
- `datasets/` - A collection of toy datasets used throughout the learning materials.
